** 최초 진행시 토큰으로 chat_id 받기
1) 텔레그램에서 본인 봇과 대화 시작 (아무 메시지 1개 보내기)
2) 브라우저 주소창에 아래 URL 입력 (토큰 부분만 본인 것으로 교체)
   https://api.telegram.org/bot<여기에_토큰_붙여넣기>/getUpdates
3) 응답 JSON 에서 "chat":{"id": ...} 의 id 숫자가 본인 chat_id
   예시 응답:
   "chat": {
             "id": <본인_chat_id_숫자>,
             "first_name": "<이름>",
             "type": "private"
           }
4) 이 숫자를 .env 의 ALLOWED_CHAT_IDS 에 넣음

=== Windows PowerShell 에서 실행 ===

## 0. 프로젝트 폴더로 이동
cd "C:\Users\user\Documents\개발\AI\study\Auto_Coupon_Register"

## 1. PowerShell 실행 정책 임시 허용 (이 창에서만 적용)
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

## 2. (최초 1회 또는 venv가 깨졌을 때) venv 만들기
##    기존 .venv 폴더가 있고 Activate.ps1 을 못 찾으면 먼저 삭제:
Remove-Item -Recurse -Force .venv
python -m venv .venv

## 3. venv 활성화 — 성공하면 프롬프트 앞에 (.venv) 가 붙음
.\.venv\Scripts\Activate.ps1

## 4. (최초 1회) 의존성 + PyInstaller 설치
pip install -r requirements.txt
pip install pyinstaller


=== 빌드 ===

## 기존 GUI 버전 (Tkinter)
pyinstaller --noconsole --onefile soulstrike_coupon_auto.py

## 텔레그램 봇 버전 (트레이 아이콘 모드 - 콘솔 안 뜸)
pyinstaller coupon_bot.spec
## 결과물: dist\coupon_bot.exe
## 실행 시 우측 하단 트레이에 파란 아이콘이 생김. 우클릭 → 로그 열기 / 종료.

== 실행오류시 ==
exe를 실행해도 트레이 아이콘이 안 뜨면 dist\bot.log 파일을 확인
시작 단계 오류(.env 누락 등)는 Windows 메시지박스로 알림
